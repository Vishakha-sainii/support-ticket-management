# /review-spec

Act as a Senior Software Architect.

Review all files under:

```text
spec/
docs/tasks.md
```

Check for:

* missing requirements
* contradictions
* inconsistent terminology
* API inconsistencies
* state-machine inconsistencies
* data-model inconsistencies
* UI/API mismatches
* test coverage gaps
* task coverage gaps
* unnecessary complexity

Do not implement application code.

Fix only unambiguous documentation inconsistencies.

Do not change requirements simply to make implementation easier.

Provide a concise review summary.
